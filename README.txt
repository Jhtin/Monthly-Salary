WORKDAY — SALARY TRACKER

Open index.html in a modern browser.

Features:
- Click calendar dates to mark/unmark worked days.
- Default rate is PHP 500/day and can be changed in Settings.
- Salary updates automatically.
- Every month has its own record and starts at zero.
- Previous months remain saved in browser localStorage.
- Monthly history, dark mode, clear-month confirmation, and print/export are included.

Important:
Data is stored locally in this browser/device. Clearing browser site data can remove it.
